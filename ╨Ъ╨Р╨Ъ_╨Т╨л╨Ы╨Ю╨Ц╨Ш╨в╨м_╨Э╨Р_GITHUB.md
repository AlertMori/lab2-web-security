# Как выложить на GitHub

Всё уже готово. Нужно только создать репозиторий и загрузить в него эту папку.

## Шаг 1. Создать репозиторий на сайте
1. Зайди на https://github.com и войди (если нет аккаунта — зарегистрируйся, бесплатно).
2. Справа вверху нажми «+» → **New repository**.
3. Repository name: например `lab2-web-security`.
4. Оставь **Public** (или Private, если преподаватель просит закрытый).
5. **НЕ** ставь галочки «Add README», «.gitignore», «license» — у нас уже всё есть.
6. Нажми **Create repository**.
7. На открывшейся странице скопируй адрес репозитория вида
   `https://github.com/ТВОЙ_ЛОГИН/lab2-web-security.git`

## Шаг 2. Загрузить папку через командную строку
Открой cmd, перейди в папку проекта и выполни команды по очереди
(замени ссылку в `git remote add` на свою из шага 1):

```
cd C:\Users\alert\Desktop\тп2
git init
git add .
git commit -m "Лабораторная 2: уязвимое приложение, эксплойты, патчи"
git branch -M main
git remote add origin https://github.com/ТВОЙ_ЛОГИН/lab2-web-security.git
git push -u origin main
```

При `git push` в первый раз откроется окно входа в GitHub — залогинься через браузер,
оно запомнит. После этого обнови страницу репозитория на сайте — все файлы будут там.

## Если git попросит имя и почту (при первом commit)
Выполни один раз (подставь свои) и повтори commit:
```
git config --global user.name "Ваше Имя"
git config --global user.email "ваша@почта"
```

## Что сдавать
Ссылку на репозиторий (адрес страницы на github.com) — в ней уже есть всё:
приложение, эксплойты, патчи и README с описанием.
